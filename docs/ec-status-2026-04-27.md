## 動作確認手順（司さんが variant 埋めた後）

1. `npm run dev` でサーバー起動
2. http://localhost:3000/p3_test.html を開く
3. 商品カードをクリック → サイズ選択 → 「カートに入れる」or 「checkout」
4. ブラウザのネットワークタブで `/api/checkout` を確認
5. レスポンスの `url` フィールドに Shopify チェックアウト URL が返る
6. その URL を踏むと Shopify 公式チェックアウト画面へ → 決済テスト

## チェックアウトフロー（コード流れ）

```
ユーザーが商品クリック
  → P3 UI で size 選択
  → cart に追加 [{id, size, qty, shopifyVariantId}]
  → /api/checkout に POST { items }
  → server.js が Shopify GraphQL cartCreate 呼び出し
  → checkoutUrl を返す
  → window.location = checkoutUrl
  → Shopify 公式 checkout で決済
  → Webhook で Gelato が自動で印刷・配送
```
