### 8.2 state machine 化されてない箇所（指摘）

- **bigBangState** は文字列リテラルを `=` で書く非正規 FSM。遷移マトリクスが loop6 内にインライン散在（行 3422, 3445, 3471 + closeChatUI L4428 + bb-logo click L3252）。**統一 transition 関数なし**。
