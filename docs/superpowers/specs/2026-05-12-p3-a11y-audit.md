## P0 — Blockers

### P0-1  Test HTMLs missing skip link
- WCAG 2.4.1 Bypass Blocks (A)
- Files: `p1_upgrade_preview.html:104`, `p2_upgrade_preview.html:45`,
  `p3_effects_test.html:83`, `p3_audio_test.html:94`
- No `<a class="skip-link">` and no semantic landmarks. Keyboard users
  cannot bypass the corner labels / chrome to reach the main scene
  controls.
- **Fix (applied):** inject `<a class="cosmos-skip-link" href="#main">…`
  + ensure target has `id="main"` and `tabindex="-1"`.

### P0-2  `cursor: none` with no keyboard equivalent
- WCAG 2.1.1 Keyboard (A) / 2.4.7 Focus Visible (AA)
- Files: `p2_upgrade_preview.html:11`, `p3_effects_test.html:17`
- Page hides cursor globally for the custom ring. Tab focus is invisible
  too because no `:focus-visible` ring is defined.
- **Fix (applied):** include `cosmos-a11y.css` which adds a
  `:focus-visible` ring (cyan / yellow accents at light=0.5) that
  survives `cursor: none`.

### P0-3  Gesture overlay traps no focus
- WCAG 2.4.3 Focus Order / 2.1.2 No Keyboard Trap (A)
- File: `p3_audio_test.html:96-98`
- The "観測を始める" overlay covers the page but Tab still reaches
  controls behind it (because they aren't `aria-hidden` / `inert`),
  and there is no `role="dialog"` semantics so SR users do not know
  the overlay is modal.
- **Fix (applied):** `role="dialog"`, `aria-modal="true"`,
  `aria-labelledby`, and `applyA11y().focusTrap(overlay)` until the
  button is activated.

### P0-4  HUD updates are silent to AT
- WCAG 4.1.3 Status Messages (AA)
- File: `cosmos-percentage-hud.js` — already has `role="status"` +
  `aria-live="polite"`. BUT the `aria-atomic` text only changes the
  *number*; the contextual change ("観測 51 → 52%, wrap") is not
  announced because the wrap-state lives in a CSS class, not in
  accessible text. SR users hear "52" / "53" with no context.
- **Fix (applied):** add `aria-label` on the host element and an
  off-screen detailed announcement when `wrapped=true` or every Nth
  pulse.

### P0-5  Mic + audio start has no SR feedback
- WCAG 1.3.3 Sensory Characteristics (A) / 4.1.3 (AA)
- File: `p3_audio_test.html:206-219`
- Mic button toggles aria-pressed (good) but the live region is the
  visible event log (not aria-live). Screen reader gets nothing on
  "mic armed / denied".
- **Fix (applied):** route log messages through `applyA11y().announce()`
  in polite priority.

### P0-6  Vestibular triggers stack without a global toggle
- WCAG 2.3.3 Animation from Interactions (AAA, but treated P0 here per
  brand a11y stance)
- Files: `cosmos-postfx.js` (bloom + afterimage), `p3_effects_test.html`
  (camera orbit lines 213-216), `cosmos-effects.js:fireBurst`,
  `cosmos-interaction.js` (auto-cycle).
- `prefers-reduced-motion` is respected for *post-fx* but the camera
  orbit in the test HTML runs unconditionally. A user with vestibular
  sensitivity who has NOT set the system flag has no in-page toggle.
- **Fix:**
  - Test HTML camera orbit now gated on `applyA11y().reduceMotion`
    (applied in p3_effects_test.html).
  - `behaviors/*` and `cosmos-effects.js` need an additional in-page
    "calm mode" toggle in a future wave (flagged below).

## P1 — Important

### P1-1  Corner labels low contrast
- WCAG 1.4.3 Contrast (Minimum) (AA)
- Files: `p1_upgrade_preview.html:8` (`--dim:#7a7a86` on `#080808`),
  `p3_effects_test.html:9` (`--dim:#6b6b78` on `#030305`),
  `p2_upgrade_preview.html:8`.
- Measured ratios: `#7a7a86` on `#080808` ≈ 4.05:1 (passes for ≥18pt,
  fails for normal). The corner labels are 10px / `letter-spacing:.32em`
  — i.e. *small text*, so fail.
- **Fix (applied):** bumped `--dim` toward `#9a9aaa` (≈ 6.5:1) in the
  test HTMLs. Source attribute name kept for minimal diff.

### P1-2  Scene pill buttons under 44×44 on touch
- WCAG 2.5.5 (AAA) / 2.5.8 Target Size (Minimum 24×24, AA in 2.2)
- File: `p3_effects_test.html:58-65` (padding 8×16, font-size 10, computed
  height ≈ 30px).
- **Fix (applied):** `cosmos-a11y.css` `@media (pointer: coarse)`
  bumps `#scene button` padding-y to 12px and `min-height: 44px`.

### P1-3  No `:focus-visible` styling anywhere in the test HTMLs
- WCAG 2.4.7 Focus Visible (AA)
- All four wave-1 HTMLs.
- **Fix (applied):** import `cosmos-a11y.css` which provides a global
  focus ring at light=0.5.

### P1-4  Konami / 'r' / 'i' / 'm' keys not advertised
- WCAG 3.3.2 Labels or Instructions (A)
- File: `cosmos-interaction.js:96-103`, `p3_audio_test.html:116`
- The hint exists visually ("r=resonance · i=revelation · m=mute") but
  is not in a labelled help dialog and there is no `?` shortcut.
- **Fix (applied):** `applyA11y()` exposes a `?`-keyed help dialog
  listing all shortcuts.

### P1-5  `outline: none` candidates without replacement
- WCAG 2.4.7
- Searched: no explicit `outline: none` in wave-1 files (good). But
  `appearance: none; border: 0` on `#scene button` (p3_effects_test.html
  :59-60) drops the default focus ring on some UAs.
- **Fix (applied):** ensured global `:focus-visible` replaces it.

### P1-6  `<canvas>` decorative but lacks `aria-hidden`
- WCAG 1.1.1 Non-text Content (A) — decorative requires `aria-hidden`.
- Files: `p1_upgrade_preview.html:106-107`, `p2_upgrade_preview.html:47`,
  `p3_effects_test.html:85`, `p3_audio_test.html:100`.
- **Fix (applied):** added `aria-hidden="true"` on all decorative
  canvases.

### P1-7  No `<main>` landmark
- WCAG 1.3.1 Info and Relationships (A) / 2.4.1
- Files: `p1_upgrade_preview.html` (no main), `p3_effects_test.html`
  (no main), `p2_upgrade_preview.html` (no main). Only `p3_audio_test.html`
  has `<main>` (line 109).
- **Fix (applied):** wrapped the visible content region in `<main
  id="main" tabindex="-1">`. (Skip-link target.)

### P1-8  Canon button labels lack lang markers
- WCAG 3.1.2 Language of Parts (AA)
- File: `p3_audio_test.html:170-181` — buttons mix English canon names
  (`resonance`, `revelation`) with Japanese descriptions (`共鳴`).
- **Fix (applied):** wrap the English `<strong>` in `<span lang="en">`
  and the description in `<span lang="ja">`.

### P1-9  Mute button text-only, no icon, no `aria-label`
- WCAG 4.1.2 Name, Role, Value (A)
- Files: `p3_audio_test.html:103`, `cosmos-audio.js` has no UI.
- "mute" label is fine, but state-on-press could be clearer.
- **Fix (applied):** `aria-label="audio mute toggle"` + announce state
  change via live region.

### P1-10  Pre-roll caption purely decorative
- WCAG 1.3.3
- File: `p1_upgrade_preview.html:67-71` — "consciousness · not yet
  condensed". OK for sighted but invisible to AT. If meaningful, must
  reach AT.
- **Fix (applied):** `aria-live="polite"` on `#cap` so the phrase reaches
  AT on entry.

### P1-11  Reset / replay buttons lack explicit type
- HTML semantics / WCAG 4.1.2
- `<button id="reset">`, `<button id="replay">` in `p3_audio_test.html`
  and `p1_upgrade_preview.html:138` — all are inside no `<form>`, so
  default `type="submit"` is harmless, but explicit `type="button"`
  prevents future regressions.
- **Fix (applied):** added `type="button"` where missing.

## P2 — Nice-to-have

### P2-1  Logo speaking / canon utterance not announced
- WCAG 1.2.1 Audio-only Alternative (A) — applies to non-decorative
  audio. Canon sounds are decorative ambience; arguably exempt. But
  announcing canon name aids comprehension.
- **Recommendation:** `applyA11y().announce('speaking: ' + canon, 'polite')`
  inside `wireInteractions.fire()`. **Flagged for next wave**
  (cosmos-interaction.js not edited; only audio test HTML hooked).

### P2-2  HUD cognitive load
- WCAG 3.2.5 Change on Request (AAA)
- `cosmos-percentage-hud.js` — no way to hide. For a calmer mode the
  HUD should be collapsible.
- **Recommendation:** add a `compact: true` toggle binding to a kbd
  shortcut. Flagged for next wave.

### P2-3  Color is sole channel for RGB/CMY bar
- WCAG 1.4.1 Use of Color (A) — the seg colors carry meaning only via
  hue.
- The bar is `aria-hidden="true"` (line 29) so AT is fine. For low-vision
  sighted users, adding letter glyphs (R/G/B/C/M/Y) inside each segment
  would help.
- **Recommendation:** future wave.

### P2-4  Lang switcher (when wired) must update html[lang] + dir
- WCAG 3.1.2
- No language switcher exists in the test HTMLs yet (i18n module is
  separate). Note for integration phase: setting `document.documentElement.lang`
  on switch is mandatory; `dir` stays `ltr` for JP/EN both.

### P2-5  `cosmos-effects.js` burst flashes
- WCAG 2.3.1 Three Flashes (A) — fireBurst happens on every scene
  switch. Single flash, but stacking via rapid scene clicks could
  exceed three flashes/sec.
- **Recommendation:** debounce `fireBurst` to ≥333ms in next wave.

### P2-6  Behaviors auto-cycle (cosmos-integration.js:511)
- 12s auto-cycle is gated on reduce-motion (good). But there is no
  user-facing pause/play. WCAG 2.2.2 Pause, Stop, Hide (A) — applies to
  content moving > 5s.
- **Recommendation:** expose a pause toggle in chrome.

### P2-7  Help dialog hides nothing else
- When `applyA11y().openHelp()` runs, the rest of the page is not
  `aria-hidden`. Modern AT mostly respects `aria-modal`, but adding
  `inert` to the page background is safer.

## Out-of-scope flags (next wave)

These require edits to files this wave is forbidden from touching
(`behaviors/*`, `cosmos-effects.js`, `cosmos-postfx.js`,
`cosmos-layer.js`):

1. **Behavior change announcement** — `cosmos-integration.js`
   `bus.emit('scene:reduce-motion')` should also emit
   `scene:behavior-change` → `applyA11y().announce()` plumbing.
2. **`fireBurst` debounce** — `cosmos-effects.js:fireBurst` should
   reject calls within 333ms (WCAG 2.3.1 safety margin).
3. **Bloom + afterimage stacking** — `cosmos-postfx.js` currently
   disables afterimage on reduce-motion but bloom intensity is not
   lowered. Recommend bloom strength × 0.5 when reduceMotion.
4. **`light_bridge_accent.js`, `ring_resonance.js`** — pulsing rings
   need a frame-rate cap when reduce-motion is set (idle_static is
   selected, but the bridge layer still draws).
5. **Mic privacy** — `cosmos-audio.js:connectMic` already opt-in, but
   should announce "microphone access requested" via live region
   before the browser prompt.
6. **Speech ring captions** — `particle_speech_rings.js` should expose
   the active canon name as text (already in roadmap, confirm AT path).
