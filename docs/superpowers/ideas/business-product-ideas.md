## 1. Lens — Philosophy Chatbot SaaS
- **Pitch**: 「答えを返さず、視点を返す AI」を企業サイトに 1 行で埋込。傾聴 BOT / 内省ジャーナル用途。
- **Customer**: コーチング会社、瞑想アプリ、教育機関、寺院。
- **Price**: $29 / mo (個人) / $290 / mo (企業 / WL ロゴ非表示) / $1,990 一回（自社モデル運用 OSS ライセンス）。
- **GTM**: HP の AI Chat Lens モードをそのまま PR、「これを 1 行でうちにも」。X / IndieHackers / Awwwards。
- **Why inryokü**: 既に最初の実装が HP に動く（idea 13）。差別化は哲学そのもの。

## 2. 円環ジェネレータ API（17 canon Visualizer as a Service）
- **Pitch**: テキストを送ると 17 canon にマップした円環 SVG / WebGL 動画を返す API。
- **Customer**: ブロガー、ニュースレター、瞑想アプリ、ライブイベント VJ、無人カフェの環境映像。
- **Price**: 従量 $0.002 / req、月 $19 minimum。動画 mp4 出力は $0.05 / 5s。
- **GTM**: 月 1 本生成ギャラリーで実例蓄積 → API ドキュメントを公開。Vercel / Cloudflare Workers でホスト。
- **Why inryokü**: 既存 `particle_rings.js` を WL 化。誰も持っていない独自視覚言語。

## 3. brand identity for the invisible（B2B ブランディング）

- **Customer**: 個人事業主 / スモールビジネス。
- **Price**: 248,000 円 / 案件（3 週間納品）。コアの差別化 = 動的ロゴ + 哲学解説書 1p 同梱。
- **GTM**: 既存 C プランの上位 SKU として明示。ココナラ高単価出品。
- **Why inryokü**: HP 自体がポートフォリオ最高点。

## 4. 観測会 — IRL イベント（月 1）
- **Pitch**: 都内 / 大阪のギャラリーで 3 時間、定員 12。最初の 1 時間は誰も話さない。プロジェクタに HP を映写、参加者の動きが粒子に反映（前述 Multiplayer）。
- **Customer**: 既存ファン + デザイン / 哲学コミュニティ。
- **Price**: 4,800 円 / 名 × 12 = 57,600 円 / 回。会場代差引き利益 30,000 円目標。
- **GTM**: Peatix + コミュニティ告知。回ごとに canon 1 つテーマ化。
- **Why inryokü**: 「観測 = +1%」を物理空間で。LP 写真素材として 12 倍化。

## 13. 「101% 証明書」NFT 風コレクティブル（厳格判定）
- **Pitch**: 観測メーター 100% 到達者だけが受け取れる、ローカル保存の SVG 証書（オフチェーン）。
- **Customer**: 既存ファンのみ。販売しない。
- **Price**: 0 円。流通不能（個人 ID 紐付け、譲渡不可、再生成可）。
- **GTM**: なし。秘密。
- **Why inryokü**: NFT の投機性は哲学に矛盾するため、敢えて非売非トレード = ステートメント。**チェーン化はしない**（IP / 環境負荷 / 投機の理由で却下）。
