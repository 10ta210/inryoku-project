## 3. 各 HTML への配線パターン

### 3.1 共通: 末尾に i18n.js / i18n.css を読み込み

各 `<body>` 末尾 (閉じタグ直前) に:

```html
<div class="i18n-toggle-host" aria-hidden="true"></div>
<script src="/i18n.js" defer></script>
<link rel="stylesheet" href="/i18n.css">
```

`i18n-toggle-host` は単なるアンカー用プレースホルダ。実際のトグル UI は `i18n.js` が `document.body` 末尾に `#inryoku-lang-toggle` を自動注入するので、`host` div は将来位置を制御したくなった時のためのフック。

### 3.2 textContent 翻訳

```html
<h1 data-i18n="legal.title">特定商取引法に基づく表記</h1>
<p data-i18n="privacy.body.collect">注文処理に必要な情報…</p>
```

初回 apply 時に i18n.js が `data-i18n-orig` に元日本語を退避するので、`?lang=ja` に戻すと完全復元される。

### 3.3 `<title>` も翻訳対象

`<title data-i18n="legal.meta.title">` のように指定すると、i18n.js の汎用ハンドラが textContent を上書きしてくれる (jsdom テスト確認済)。

### 3.4 placeholder 等の属性翻訳

今回の法定ページにはフォーム入力がないため `data-i18n-attr` の付与は無し。
将来お問い合わせフォームを追加する場合のテンプレ:

```html
<input data-i18n-attr="placeholder:contact.name.placeholder,aria-label:contact.name.label">
```

`attr:key,attr2:key2` のカンマ区切り。テストはこの構文の妥当性とキー存在をチェックする。

### 5.3 哲学整合チェック

| 日本語 | 推奨英訳 |
|---|---|
| 50% → 101% | **50% → 101%** (記号として両言語共通) |
| 観測 / 観測者 | observe / the observer |
| 見えないものの可視化 | making the invisible visible |
| グレーの中に虹 | the rainbow within grey |
| グレー / grey | **grey** (米英の grey 統一。"gray" は使わない) |
| 引力 | inryokü (gravity) |

`offline.quote` の「観測すれば、50% は 101% になる」/「observe, and the 50% becomes 101%.」のように、両言語で同じ哲学的余白を残すのが原則。

## 8. 既知の小さな注意点

### offline.html の retry → reconnect

`offline.html` の retry ボタンはオンライン復帰時に JS が `textContent = 'reconnect'` に書き換える。
i18n.js が即時 apply するのは初回 / 言語切替時のみなので、復帰イベント中は JS 側の上書きが勝つ。
将来 reconnect 文言も翻訳したくなったら:

```js
btn.textContent = window.inryokuI18n.t('offline.reconnect', 'reconnect');
```

辞書には `offline.reconnect` を既に登録済み (ja: "reconnect", en: "reconnect")。

### success.html のシーケンシャル fade-in

`success.html` は IIFE が DOM ready 直後に textContent を読まずクラスだけ追加するので、i18n の textContent 上書きと衝突しない。安全。

### `<title>` の翻訳

i18n.js は `document.querySelectorAll('[data-i18n]')` で title も拾う。
ブラウザは title 変更で自動的にタブ表示を更新する。動作確認済 (jsdom + manual)。
