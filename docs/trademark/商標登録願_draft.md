# inryokü 商標登録出願 — 下書き & 手順 (2026-10-14)

> ロゴは「特許」ではなく「商標」で守る。出願先は特許庁。
> 出願そのもの (法人名・住所の記入、支払い、提出) は司さん (会社の代表として) か弁理士が行う。
> ⚠️ 金額・様式は作成時点の情報。提出前に特許庁サイトで最新版を確認すること。

## 1. 出願する商標 (2件の想定)

| # | 商標 | 種類 | デザイン |
|---|------|------|----------|
| A | O + i のロゴマーク | 図形商標 | Codex で平面版を制作 (`prompts/04_trademark_logo_codex.md`) |
| B | INRYOKU | 標準文字 | 不要 (特許庁の書体で登録される) |

- B は「ü」が標準文字の一覧に入っていない可能性が高いため、ウムラウトなしの `INRYOKU` で出す想定 (要確認)
- 予算を抑えるなら A だけでも可

## 2. 決めること (提出前に司さんが決定)

- [ ] ロゴは白黒版で出すか、カラー版で出すか
      (白黒 = 色違いまで広く守れる / カラー = 虹色の点込みで守る)
- [ ] B (INRYOKU 文字) も出すか
- [x] 出願人は**法人名義** (2025年7月設立の大阪の会社) で出す
      → 公報・J-PlatPat に載るのは法人名と本店所在地。司さん個人のフルネームは出ない
- [ ] 登記どおりの正式な商号を確認 (履歴事項全部証明書 or 法人番号指定通知書)
      全角/半角・大文字/小文字・「株式会社」が前か後ろか まで一字一句合わせる
      ※ 埼玉に別会社「株式会社ｉｎｒｙｏｋｕ」(2015年以前から存在) があるので取り違え注意
- [ ] 自分で出すか、弁理士・オンライン商標サービスに頼むか

## 3. 費用 (自分で出す場合、2025年4月時点の料金表)

| | 1区分 | 計算式 |
|---|---|---|
| 出願料 | 12,000円 | 3,400円 + 8,600円 × 区分数 |
| 登録料 (10年) | 32,900円 | 32,900円 × 区分数 |
| 登録料 (5年分割) | 17,200円 × 2回 | 17,200円 × 区分数 |
| **合計 (10年一括)** | **44,900円** | |

- A と B の2件を第25類で出すと約9万円
- 紙で出す場合は別途「電子化手数料」がかかる

## 4. 手順

1. **先に同じ商標がないか調べる** — J-PlatPat (https://www.j-platpat.inpit.go.jp/)
   - 商標検索 → 称呼 (読み) で「インリョク」、区分 25 で検索
   - 文字で「INRYOKU」「引力」も検索
   - 図形の似たロゴ調査は難しいので、不安なら弁理士に任せる
2. **ロゴの出願用画像を用意する** — Codex 制作分から選ぶ
   - 白黒: PNG / GIF / BMP (モノクロ2値)
   - カラー・陰影あり: JPEG (JFIF)
3. **願書を出す** — 下の「5. 願書の下書き」を使う
   - インターネット出願 (電子証明書が必要。マイナンバーカードでも可) か、紙で郵送
4. **審査を待つ** — 通常は約1年
   - すでに商品に使っているので「早期審査」を申請すると短くなる
     (Shopify の商品ページ・販売実績のスクショが証拠になる)
5. **登録査定が届いたら30日以内に登録料を払う** → 登録完了

### 指定商品のメモ
- 「被服」で Tシャツ・パーカーは入る
- 同じ第25類の中なら商品を増やしても料金は同じ (帽子・靴下・履物など)。
