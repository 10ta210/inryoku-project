# 商標出願用ロゴ制作プロンプト (Codex 向け)

## 使う場面
inryokü ロゴを特許庁に**商標登録出願**する時、出願書類に貼る「平面版ロゴ画像」を Codex に作ってもらう。
(※ ロゴは「特許」ではなく「商標」で守る。出願先は同じ特許庁)

関連: `docs/trademark/商標登録願_draft.md` (願書の下書き・手順)

## コピペ用

```
inryokü のロゴを特許庁に商標登録出願する。
出願書類に貼る「平面版ロゴ画像」を作ってほしい。

## 元になるロゴ
- inryoku_logo_icon.png (671×953, RGBA)
  = 銀色の卵形の輪 (O) の中に「i」。i の縦棒は下に向かって細くなる円錐形、
    i の点は虹色の球。O = 全体 / i = 自己 という意味がある。
- 3D の元データ: inryoku_logo_3d.blend / docs/blender-logo-2026-04-29.md
  (卵殻・窓・I コーンの形状パラメータが書いてある)

## 作るもの (すべて docs/trademark/ に新規作成)
1. 白黒版 (第一候補)
   - tm_logo_mono.svg
   - tm_logo_mono.png … モノクロ2値 (白地に黒、グレーなし・アンチエイリアスなし)、
     945×945px (= 8cm角 @300dpi)、ロゴは中央、上下左右に余白
2. カラー版 (比較用)
   - tm_logo_color.svg
   - tm_logo_color.jpg … JPEG (JFIF)、945×945px、白地、ベタ塗り
     輪と i はグレーのベタ、点は虹色 (RGBCMY の帯) をグラデーション・光沢なしで表現
3. 比較シート
   - tm_logo_compare.html … 元ロゴ / 白黒版 / カラー版 を横並び。
     実寸 8cm と、縮小 1.5cm の両方で見え方を比較できるようにする

## 守ること
- 形の比率は元ロゴを正確にトレースする (輪の太さ、窓の形、i の円錐の角度、点の位置と大きさ)
- 陰影・光沢・メタリック・3D 表現は全部なくす。輪郭がはっきりした平面図形にする
- 文字 (inryokü 等) は入れない。図形だけ
  (文字の INRYOKU は「標準文字」で別に出願するのでデザイン不要)
- 白黒版では、虹色の点は黒の塗りつぶし円にする
- 既存のロゴ画像・サイトのコードは一切変更・削除しない (新規ファイルのみ)
- Canvas 2D (getContext('2d')) は使わない。PNG/JPEG 化は sharp や resvg などの CLI で
- 個人名・住所などはファイルに一切書かない

## 終わったら
- 白黒版とカラー版の画像を見せて、元ロゴと違うところがあれば列挙して報告
- デザインの最終決定は司さん。勝手に確定しないで、修正点を聞いてから仕上げる
```
