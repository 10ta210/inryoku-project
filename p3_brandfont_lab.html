★111 · APERTURE PIXEL

各文字に小さな黒い core が空く。文字は event horizon。

コア生成の哲学が一番強く入る案。「中心は黒、外に光」の構造そのもの。pixel の硬さは保ちつつ、各文字に物理的な穴があるように見える。読みやすさ◎ (輪郭が rim light として強く残る)。

font-size
desktop 38–46px / mobile 26–32px
letter-spacing
0.06em (狭め — coreリング同士が呼応)
weight
regular (Press Start 2P 単一)
chromatic
不要 (内側コアで十分な深度)
glow
0/4/14px 三層、α 1.0 / 0.7 / 0.35
aperture
::before scale(0.62) #000 + ::after scale(0.62) stroke 0.5px
登場アニメ
aperture-open: scale 1.6 → 1.0 + コア径 0 → 0.62 (1.4s ease-out, 各文字 +90ms stagger)

★213 · GENESIS BOOT

左から順に灯る。コアから時系列で世界が生まれる。

起動順 (黒 → コア → ロゴ → 粒子 → 服 → UI) の中で、ブランドネームが最後に「生成」される段階を視覚化。loop なしで「一度生まれたら消えない」のも哲学整合。

font-size
desktop 40–48px / mobile 28–34px
letter-spacing
0.08em
weight
regular
chromatic
0.5px split を idle で重ねる
glow
初期 brightness 2.5 + blur 2px → 1.0 + 0px
登場アニメ
boot-in: 2.4s, 各文字 +180ms stagger, 100% で固定 (loop しない)
idle
charFloat 8.2s (既存) のみ — boot 完了後は静か
